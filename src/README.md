# PrestaYa Fintech
Motor de microcréditos desarrollado en Java para simular, evaluar y administrar solicitudes de créditos dirigidas a emprendedores de la economía popular en Colombia.

## Objetivo

Contruir una aplicación de consola que aplique principios de programación orientada a objetos y características modernas de Java, garantizando precisión en los cálculos financieros mediante BigDecimal.

## Tecnologías
* Java 21 o superior.
* Visual Studio Code.
* Git y GitHub.

## Funcionalidades
* Simulación y evaluación de solicitudes de crédito.
* Aprobación o rechazo según el puntaje crediticio.
* Cálculo de cuotas mensuales con precisión decimal.
* Gestión de créditos para emprendedores y vivienda social.
* Administración de cartera mediante un array de capacidad fija.
* Consulta del estado de la plataforma.

## Conceptos aplicados
* Programación orientada a objetos.
* Herencia, abstracción y polimorfismo.
* Records e interfaces selladas.
* Pattern matching en switch.
* Enumeraciones (enum).
* Manejo de importes con BigDecimal.
* Control de versiones con Git.
